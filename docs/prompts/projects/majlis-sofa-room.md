# اللقطات القريبة للتفاصيل

لقطات ماكرو وتفاصيل تعرض الخامات والصنعة، لصفحات الكتالوج التسويقي.

- **المقاس الافتراضي 4:5** (صفحة كتالوج وإنستغرام). لمقاس آخر غيّر السطر الأول فقط: `1:1 square` أو `16:9 landscape` أو `9:16 vertical`.
- **أهم خطوة للدقة:** ارفع صورة المرجع المذكورة، فتكون اللقطة "تقريباً" من نفس القطعة ولا يخترع المولّد تصميماً جديداً.
- تحت كل لقطة **عنوان مقترح للكتالوج** بالعربي تضعه في التصميم مع الشعار.
- لتوحيد الكتالوج: نفس الإضاءة في كل اللقطات، ورتّب الصفحات: لقطة عريضة للفراغ، ثم لقطات التفاصيل.
