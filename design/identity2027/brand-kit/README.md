# هوية النظرة الساحرة 2027 — Magic Look Brand Kit

مكونات الهوية مستخرجة من ملفَي المصمم:
`الشعار مع الأكواد.pdf` و`دليل الهوية البصرية.pdf`.

كل الأشكال **فيكتور أصلي** من ملف PDF، بنفس الإحداثيات، ونصوص الشعار محوّلة إلى مسارات (Outlines)، فلا تحتاج الخط لفتحها.
الألوان مضبوطة على الأكواد الرسمية في الدليل.

## الألوان

| اللون | HEX | CMYK | RGB |
|---|---|---|---|
| Deep Forest Green · الأخضر الداكن | `#253A35` | 79 / 51 / 62 / 63 | 37 58 53 |
| Antique Bronze · البرونزي العتيق | `#A68356` | 29 / 42 / 66 / 20 | 166 131 86 |
| Warm Stone Beige · البيج الحجري | `#D6C9B5` | 18 / 19 / 30 / 2 | 214 201 181 |

درجات كل لون (80٪، 60٪، 40٪، 20٪، 10٪) موجودة في `colors/`.

## الخط

**Lama Sans**، وله 11 وزناً. يُستخدم للعناوين والنصوص بالعربي والإنجليزي.
الخط غير مرفق هنا: ملف PDF يحتوي فقط على الحروف المستخدمة فيه، وليس الخط كاملاً. نزّله من مصدره الرسمي.

## محتويات المجلد

| المجلد | المحتوى |
|---|---|
| `logos/horizontal/` | الشعار الأفقي (الرمز يسار والاسم يمين). SVG + PNG بعرض 3000px |
| `logos/stacked/` | الشعار العمودي (الرمز فوق الاسم). SVG + PNG بارتفاع 2000px |
| `logos/icon/` | الرمز وحده. SVG + PNG بعرض 2048px |
| `social/` | صور حسابات التواصل 1080×1080 (أخضر/أبيض/بيج) وأيقونات الموقع favicon بمقاسات 32 و180 و192 و512 |
| `colors/` | `colors.css` (متغيرات CSS)، `palette.json`، `magic-look-colors.ase` (حوامل ألوان لفوتوشوب وإليستريتور)، `palette.png` |
| `elements/` | عناصر التكوين الثلاثة: الرمز، المنحنى، حرف M. بأربعة ألوان |
| `patterns/` | الأنماط الثلاثة بنسختين: «تغشية لونية» (filled) و«خط محيط» (outline)، بالبيج والأخضر. ومعاينات على خلفية خضراء في `preview/` |
| `construction/` | مراحل تصميم الشعار السبع ومعادلة الفكرة (خطوط + عين + ML ← الرمز) |
| `mockups/` | تطبيقات الهوية: واجهة المحل، لوحة الجدار الداخلي، الرول أب، طقم القرطاسية |
| `guide-pages/` | صفحات الدليل كاملة كصور (19 صفحة) |

## نسخ ألوان الشعار

نفس الأسماء تتكرر في `horizontal` و`stacked` و`icon`:

| الاسم | الرمز (أعلى / أسفل) | الاسم العربي | Magic Look | متى يُستخدم |
|---|---|---|---|---|
| `primary` | أخضر / برونزي | برونزي | أخضر | **الأساسي**: خلفية بيضاء أو بيج فاتح |
| `secondary` | أخضر / برونزي | أخضر | برونزي | بديل على الأبيض |
| `on-green` | بيج / برونزي | برونزي | بيج | على الأخضر الداكن (اللافتات، الستوري الداكن) |
| `on-bronze` | بيج / أخضر | أخضر | بيج | على البرونزي أو البني |
| `green` · `bronze` · `beige` | لون واحد | | | الطباعة بلون واحد، الحفر، الطباعة الذهبية |
| `white` | أبيض | | | فوق الصور |
| `black` | أسود | | | الختم والفاكس والطباعة بالأبيض والأسود |

النسخ الأربع الأولى منقولة من الدليل كما هي (صفحات 4 و6 و7 وورقة الأكواد).
نسخ اللون الواحد أُضيفت للاستخدام العملي، وليست من الدليل.

## ملاحظات

- استخدم **SVG** للموقع والطباعة لأنه يتكبر بلا حدود، وPNG للسوشال والعروض. كل ملفات PNG بخلفية شفافة، ما عدا `social/` و`patterns/preview/`.
- خطوط أنماط «الخط المحيط» رفيعة جداً في الأصل (حوالي 0.1pt)، لذلك صُدّرت PNG بعرض 4000px. لا تصغّرها كثيراً.
- لفتح الشعار في إليستريتور للتعديل افتح ملف SVG مباشرة.
