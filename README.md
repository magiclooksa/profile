# الملف التعريفي لمؤسسة النظرة الساحرة MAGIC LOOK

موقع يعرض الملف التعريفي للمؤسسة بهويتها: الشعار، والأوكر والأسود والعاجي، وخطا Noto Kufi Arabic وAlmarai. مكتوب بـ TypeScript دون أي إطار عمل، وكل محتواه في ملفات JSON.

## التشغيل

يحتاج Node.js 22 أو أحدث.

```bash
npm install
npm run dev           # تشغيل محلي على http://localhost:5173
npm run dashboard     # لوحة التحكم محلياً، دون كلمة مرور
npm run catalogues    # إعادة كتابة صفحات المشاريع بعد تعديل ملفاتها يدوياً
npm run build         # فحص الأنواع ثم بناء الموقع في مجلد dist
npm test              # الاختبارات

npm run build:server  # بناء خادم الإنتاج في server-dist
npm run set-password  # كلمة مرور لوحة التحكم على السيرفر
npm start             # تشغيل خادم الإنتاج: الموقع ولوحة التحكم على المنفذ 8080

python release.py     # حزمة إصدار للسيرفر في مجلد release/ (انظر دليل النشر)
```

### النشر

يعمل الموقع على Windows Server الخاص بالمؤسسة: خادم Node.js واحد يقدّم الموقع ولوحة التحكم بكلمة مرور، وأمامه IIS للنطاق وشهادة HTTPS. خطوات التثبيت والتحديث والنسخ الاحتياطي في [docs/deploy-windows-server.md](docs/deploy-windows-server.md).

يفحص GitHub كل رفع إلى المستودع (الاختبارات وبناء الموقع والخادم) عبر `.github/workflows/ci.yml`، ولا ينشر شيئاً.

## تعديل المحتوى (قاعدة البيانات)

كل المحتوى في `public/data`، ملف لكل قسم. أسهل طريقة لتعديله لوحة التحكم (انظر «لوحة التحكم» أدناه)، ويمكن أيضاً تعديل الملف مباشرة. لا حاجة لتغيير الكود في الحالتين.

| الملف | المحتوى |
|---|---|
| `company.json` | الاسم، والنبذة، والرؤية والرسالة والقيمة، وقسم التصميم الداخلي |
| `services.json` | الخدمات وأيقوناتها |
| `products.json` | فئات المنتجات |
| `advantages.json` | لماذا النظرة الساحرة |
| `journey.json` | خطوات رحلة العمل |
| `levels.json` | مستويات التعامل |
| `projects.json` | المشاريع وصورها وطريقة عرض كل مشروع |
| `clients.json` | فئات العملاء، والشركاء، والشهادات والمشاركات |
| `contact.json` | الجوال، والبريد، والموقع، والعنوان، ورابط الخريطة |
| `ceo.json` | كلمة الرئيس التنفيذي: العنوان، والاسم، والمسمى، والصورة، والاقتباس، والفقرات، وصورة التوقيع |
| `faq.json` | الأسئلة الشائعة، تظهر في الصفحة وتُعطى لمحركات البحث ومساعدي الذكاء الاصطناعي |
| `seo.json` | إعدادات الظهور في محركات البحث (انظر القسم التالي) |
| `service-pages.json` | صفحة لكل خدمة (المجالس، الكنب، غرف النوم…): عنوانها في قوقل، ووصفها، وكلماتها المفتاحية، ونصها، وصورها، وكتالوجاتها، وأسئلتها. تُنشأ في `pages/services/<slug>.html` عند كل تشغيل أو بناء، فلا تعدّل ملفات HTML نفسها |

### البحث في الموقع

زر «بحث» في أعلى كل صفحة (أو `Ctrl+K` أو `/`) يفتح لوحة بحث في القطع والكتالوجات والمساحات والخدمات وصور الأعمال والأسئلة الشائعة. يُبنى فهرس البحث `search-index.json` تلقائياً من ملفات `public/data` عند كل بناء، فأي قطعة أو كتالوج جديد يظهر في البحث دون تعديل الكود.

البحث يعمل في المتصفح دون خادم، ويفهم:

- اختلاف الكتابة: أ/إ/آ، ة/ه، ى/ي، والتشكيل.
- صيغ الكلمة: كنبة، الكنبات، كنب.
- المترادفات واللهجة والإنجليزية: صوفا = كنبة = sofa، دولاب = خزانة، ثريا = إضاءة، والألوان والخامات بالعربي والإنجليزي. القائمة في `CONCEPTS` داخل `src/application/search.ts`، وتُوسَّع بإضافة كلمات إليها.
- الأخطاء الإملائية، مع اقتراح «هل تقصد؟».
- البحث بالصوت في المتصفحات التي تدعمه، وروابط بحث قابلة للمشاركة مثل `index.html?q=مجلس`.

### الظهور في محركات البحث ومساعدي الذكاء الاصطناعي (SEO وGEO)

عند البناء (`npm run build`) يكتب الموقع لكل صفحة من `seo.json` وملفات المحتوى:

- العنوان والوصف والكلمات المفتاحية والرابط الأساسي (canonical) ومعاينة الروابط في واتساب وX.
- بيانات schema.org: المؤسسة كنشاط محلي بخدماتها ومنتجاتها والرئيس التنفيذي، والأسئلة الشائعة (FAQPage)، وقطع كل كتالوج مع مسار التنقل.
- نص الصفحة كاملاً بـ HTML عادي، لمحركات البحث ومساعدي الذكاء الاصطناعي التي لا تشغّل JavaScript.
- `sitemap.xml` و`robots.txt` و`llms.txt` (ملخص المؤسسة لمساعدي الذكاء الاصطناعي).

حقول `seo.json`:

| الحقل | المعنى |
|---|---|
| `siteUrl` | رابط الموقع الكامل وينتهي بـ `/`؛ غيّره عند الانتقال إلى نطاق خاص |
| `title` و`description` | عنوان الصفحة الرئيسية ووصفها في نتائج البحث (الوصف بين 120 و160 حرفاً) |
| `keywords` | الكلمات المفتاحية |
| `image` | صورة المشاركة في واتساب وX وغيرها ونصها البديل (PNG أو JPEG). يُقرأ نوعها ومقاسها من الملف عند البناء: الصورة المربعة تظهر بطاقة صغيرة، والعريضة (مثل 1200×630) بطاقة كبيرة. صفحات المشاريع والقطع تستخدم صورها الخاصة |
| `business` | نوع النشاط في schema.org، والمدينة والمنطقة والإحداثيات، وساعات العمل مثل `"Sa-Th 09:00-22:00"`، ونطاق الأسعار، ومناطق الخدمة. `null` يعني غير معروف ويُحذف من البيانات |
| `social` | روابط الحسابات الرسمية كاملة (إنستغرام، X، تيك توك، سناب شات، خرائط Google) |
| `verification` | رمز التحقق من Google Search Console (`google`) وBing Webmaster Tools (`bing`) |
| `aiCrawlers` | `true` يسمح لمساعدي الذكاء الاصطناعي (ChatGPT وClaude وPerplexity وGemini) بقراءة الموقع والاستشهاد به، و`false` يمنعهم |

ملاحظة: محركات البحث تقرأ `robots.txt` و`sitemap.xml` من جذر النطاق، فتأكد أن `siteUrl` في `seo.json` هو نطاق الموقع على السيرفر.

**القيمة `null` تعني أن المعلومة لم تتوفر بعد**، فتظهر في الصفحة بين أقواس مثل [رقم الجوال]. اكتب القيمة بدلها لتظهر.

### إضافة الصور والفيديوهات

خلفية الـ hero تُحدد في الحقل `hero` داخل `public/data/company.json`. يستخدم الموقع الفيديو المحدد مع صورة `poster` أثناء التحميل، وتدرّج داكن فوقه لإظهار الشعار والنصوص. تعمل الخلفية تلقائياً وبشكل متكرر مع كتم الصوت وزر لتفعيله. تملأ الخلفية مساحة القسم، لذلك قد تُقص أطرافها لتناسب شاشة الجوال؛ إعدادات نسب عرض صور وفيديوهات المعارض مستقلة عنها.

ضع الصور في `public/images/projects` (أو أي مجلد داخل `public`)، ثم اكتب مسارها في `src`:

```json
{ "src": "images/projects/villa-majlis.jpg", "caption": "المجلس الرئيسي" }
```

يمكن خلط الصور والفيديوهات داخل قائمة `images` نفسها، وكذلك استخدام الفيديو في أي حقل وسائط. ضع الفيديو في `public/videos/products` ثم أضف مثلاً:

```json
{
  "type": "video",
  "src": "videos/products/majlis.mp4",
  "poster": "images/products/01-360-view-angles-bfa3cf86ae.webp",
  "caption": "جولة في المجلس"
}
```

حقل `poster` اختياري. يُكتشف الفيديو تلقائياً من امتداد الملف، واستخدم `type: "video"` للروابط التي لا تحتوي على امتداد. يُفضل MP4 بترميز H.264 لتوافق المتصفحات.

الضغط على الصورة يفتحها كاملة في شاشة عرض خاصة، مع زر للتكبير والتصغير وإمكانية تحريك الصورة المكبرة بالتمرير أو اللمس. يُغلق العارض بزر «إغلاق» أو مفتاح Escape، ويتوقف تشغيل الفيديو في الخلفية أثناء عرض الصورة.

يمكن تحديد نسبة العرض لكل صورة أو فيديو بإضافة `aspectRatio` إلى العنصر نفسه في JSON:

```json
{
  "images": [
    {
      "src": "images/projects/villa-majlis.jpg",
      "caption": "المجلس الرئيسي",
      "aspectRatio": "16:9"
    },
    {
      "src": "videos/products/majlis.mp4",
      "type": "video",
      "caption": "جولة في المجلس",
      "aspectRatio": "9:16"
    }
  ]
}
```

- `"9:16"`: إطار طولي.
- `"16:9"`: إطار أفقي.
- `"auto"` أو `null` أو حذف الحقل: اختيار تلقائي من أبعاد الملف، طولي للملفات الطولية وأفقي للأفقية والمربعة.

النسبة المحددة في JSON لها الأولوية حتى لو اختلفت عن أبعاد الملف، وتُطبق قبل تحميله وفي شاشة تكبير الصور أيضاً. تظهر الوسائط كاملة دون تمديد أو قص، مع فراغ حولها إذا اختلفت نسبتها عن الإطار. في عرض `compare` يحدد حقل `before.aspectRatio` إطار المقارنة المشترك؛ يُفضل إعطاء `before` و`after` النسبة نفسها. في الوضع التلقائي يستخدم الإطار `16:9` مؤقتاً حتى تُحمّل أبعاد الملف.

تعمل الفيديوهات تلقائياً وبشكل متكرر داخل الصفحة، وتبدأ مكتومة مع زر «تشغيل الصوت» يتحول إلى «كتم الصوت». يتوقف الفيديو عند خروجه من الشاشة أو إخفاء تبويب الصفحة أو الانتقال إلى شريحة أخرى. يبقى عرض الشرائح على الفيديو ليتمكن من التكرار حتى يختار الزائر عنصراً آخر. إذا منع المتصفح التشغيل التلقائي تظهر أدوات التشغيل اليدوي.

### طرق عرض المشاريع

لكل مشروع حقل `layout`:

- `mosaic`: صورة كبيرة وحولها صور أصغر.
- `slideshow`: عرض يتبدل تلقائياً مع صور مصغرة للتنقل.
- `compare`: شريط قبل وبعد، ويحتاج الحقلين `before` و`after`، والصور في `images` تظهر بجانبه.
- `filmstrip`: شريط صور طولية يتحرك بالسحب أو بالأسهم.

`colors` قائمة ألوان HEX تظهر كعينات، مثل `["#7B5D08", "#F4F0E8"]`.

إذا كان في ملف خطأ، تعرض الصفحة اسم الملف والحقل المقصود، مثل `projects.json[0].colors[0]`.

## البنية

يتبع الكود البنية النظيفة (Clean Architecture): كل طبقة تعتمد على الطبقة التي تحتها فقط، فالمنطق لا يعرف شيئاً عن المتصفح أو الملفات أو Vite.

```
.
├── pages/             صفحات HTML (جذر Vite)، وعنوان كل صفحة في الموقع هو مسارها هنا
│   ├── index.html … contact.html   الصفحات الرئيسية
│   ├── villa-wood.html             قالب الكتالوج، تُنسخ منه صفحات المشاريع
│   ├── <مشروع>.html                تُكتب بالأمر npm run catalogues، فلا تعدّلها يدوياً
│   ├── dashboard.html              لوحة التحكم
│   └── services/                   صفحات الخدمات، تُكتب عند كل تشغيل (خارج Git)
├── public/            يُنسخ كما هو إلى الموقع: data/ (المحتوى) وimages/ وvideos/ وassets/
├── src/
│   ├── domain/            الكيانات والواجهات (Ports)، دون أي اعتماد خارجي
│   │   ├── entities.ts          نموذج الملف التعريفي
│   │   ├── villa.ts             نموذج الكتالوج

│   │   ├── search.ts            وثيقة البحث
│   │   ├── content.ts           المحتوى كوثائق JSON، وواجهات المستودع ومكتبة الوسائط والتحقق

│   │   ├── search.ts            البحث بالعربية
│   │   └── content/             لوحة التحكم: تسمية الوثائق وتجميعها، والتحقق قبل الحفظ، والأرقام
│   ├── infrastructure/    التنفيذ الفعلي للواجهات (Adapters)

│   └── assets/            رموز الهوية المضمّنة في الكود
├── server/            خادم الإنتاج (Node.js دون مكتبات إضافية)
│   ├── main.ts              نقطة التركيب: تشغيل الخادم
│   ├── config.ts            الإعدادات من server.config.json
│   ├── http/                الملفات الثابتة، وتسجيل الدخول والجلسات
│   ├── content/             واجهة لوحة التحكم وملفات المحتوى والنسخ السابقة والرفع

│   └── scripts/             ضبط كلمة المرور
```

## لوحة التحكم

على السيرفر: `https://النطاق/dashboard.html` بكلمة المرور. على الجهاز: `npm run dashboard` دون كلمة مرور.

تعرض اللوحة أرقام الموقع، وكل ملفات `public/data` مجمّعة بأسماء عربية: الهوية والتواصل، وأقسام الموقع، والكتالوجات، والصفحات، والإعدادات. لكل ملف:

- **نموذج** يُبنى من شكل الملف: الحقول النصية، والقوائم مع الإضافة والترتيب والحذف، ومنتقي الألوان، ومعاينة الصور والفيديوهات مع اقتراح مسارات الملفات الموجودة، وزر **رفع** لإضافة صورة أو فيديو جديد.
- **JSON** للتعديل المباشر.
- **حفظ** (أو `Ctrl+S`): يُفحص الملف بالقواعد نفسها التي يقرأ بها الموقع بياناته، فإن كان فيه خطأ لا يُحفظ وتظهر رسالة بالحقل المقصود. بعد الحفظ يُعاد بناء الموقع تلقائياً، وتظهر حالة النشر في القائمة الجانبية.
- تُحفظ النسخة السابقة من كل ملف قبل تغييره (آخر 30 نسخة في `storage/history`).
- تنبيه قبل مغادرة صفحة فيها تعديلات غير محفوظة.

الحماية: كلمة مرور مشفّرة (scrypt)، وجلسة لمدة 12 ساعة في cookie من نوع HttpOnly وSameSite=Strict، وحماية من CSRF، وإيقاف الدخول ربع ساعة بعد 10 محاولات خاطئة.

الحفظ يكتب JSON بمسافتين، فقد تتغير طريقة تنسيق ملف مكتوب يدوياً عند أول حفظ دون أن يتغير محتواه.

## الحركة

- شعار LM يظهر عند فتح الصفحة وتمر عليه لمعة ذهبية.
- الأقسام تصعد بنعومة عند ظهورها، وخط رحلة العمل يمتلئ خطوة بعد خطوة.
- نقش الهوية يتحرك ببطء في الخلفية، والأيقونات ترتسم عند مرور الماوس.
- كل الحركة تتوقف لمن فعّل خيار تقليل الحركة في جهازه، والمحتوى ظاهر دائماً دون انتظار الحركة.
- الوضع الداكن يتبع إعداد الجهاز.
