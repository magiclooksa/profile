# الملف التعريفي لمؤسسة النظرة الساحرة MAGIC LOOK

موقع من صفحة واحدة يعرض الملف التعريفي للمؤسسة بهويتها: الشعار، والأوكر والأسود والعاجي، وخطا Noto Kufi Arabic وAlmarai. مكتوب بـ TypeScript دون أي إطار عمل، وكل محتواه في ملفات JSON.

## التشغيل

يحتاج Node.js 18 أو أحدث.

```bash
npm install
npm run dev        # تشغيل محلي على http://localhost:5173
npm run build      # فحص الأنواع ثم بناء نسخة النشر في مجلد dist
npm run preview    # معاينة نسخة النشر
npm test           # الاختبارات
```

ارفع محتوى مجلد `dist` إلى أي استضافة ملفات ثابتة (Netlify، Vercel، GitHub Pages، أو استضافة عادية). المسارات نسبية، فيعمل الموقع من أي مجلد.

## تعديل المحتوى (قاعدة البيانات)

كل المحتوى في `public/data`، ملف لكل قسم. عدّل الملف ثم أعد تحميل الصفحة، ولا حاجة لتغيير الكود.

| الملف | المحتوى |
|---|---|
| `company.json` | الاسم، والنبذة، والرؤية والرسالة والقيمة، وقسم التصميم الداخلي |
| `services.json` | الخدمات وأيقوناتها |
| `products.json` | فئات المنتجات |
| `advantages.json` | لماذا النظرة الساحرة |
| `journey.json` | خطوات رحلة العمل |
| `levels.json` | مستويات التعامل |
| `projects.json` | المشاريع وصورها وطريقة عرض كل مشروع |
| `clients.json` | فئات العملاء، والشركاء، والشهادات والمشاركات |
| `contact.json` | الجوال، والبريد، والموقع، والعنوان، ورابط الخريطة |

**القيمة `null` تعني أن المعلومة لم تتوفر بعد**، فتظهر في الصفحة بين أقواس مثل [رقم الجوال]. اكتب القيمة بدلها لتظهر.

### إضافة الصور

ضع الصور في `public/images/projects` (أو أي مجلد داخل `public`)، ثم اكتب مسارها في `src`:

```json
{ "src": "images/projects/villa-majlis.jpg", "caption": "المجلس الرئيسي" }
```

### طرق عرض المشاريع

لكل مشروع حقل `layout`:

- `mosaic`: صورة كبيرة وحولها صور أصغر.
- `slideshow`: عرض يتبدل تلقائياً مع صور مصغرة للتنقل.
- `compare`: شريط قبل وبعد، ويحتاج الحقلين `before` و`after`، والصور في `images` تظهر بجانبه.
- `filmstrip`: شريط صور طولية يتحرك بالسحب أو بالأسهم.

`colors` قائمة ألوان HEX تظهر كعينات، مثل `["#7B5D08", "#F4F0E8"]`.

إذا كان في ملف خطأ، تعرض الصفحة اسم الملف والحقل المقصود، مثل `projects.json[0].colors[0]`.

## البنية

يتبع الكود البنية النظيفة (Clean Architecture): كل طبقة تعتمد على الطبقة التي تحتها فقط.

```
src/
├── domain/            الكيانات والواجهات، دون أي اعتماد خارجي
│   ├── entities.ts          نموذج الملف التعريفي (Profile وProject وغيرها)
│   └── ProfileRepository.ts واجهة مصدر البيانات
├── application/       حالات الاستخدام
│   └── GetProfile.ts        تحميل الملف التعريفي وتجهيزه للعرض
├── infrastructure/    مصادر البيانات الفعلية
│   ├── decoders.ts          أدوات تحقق صغيرة من بيانات JSON
│   ├── schemas.ts           شكل كل ملف JSON
│   └── JsonProfileRepository.ts قراءة ملفات public/data
├── presentation/      العرض والتفاعل
│   ├── App.ts               تركيب الصفحة
│   ├── components/          قسم لكل ملف
│   ├── galleries/           طرق عرض المشاريع الأربع
│   ├── behaviors/           الحركة عند التمرير، وحالة القائمة، وخط رحلة العمل
│   ├── dom.ts               منشئ عناصر آمن (لا يستخدم innerHTML للنصوص)
│   └── icons.ts             الأيقونات ونقش الهوية
├── styles/            tokens وbase وsections وgalleries
└── main.ts            نقطة التركيب: تربط الطبقات ببعضها
```

لنقل البيانات لاحقاً إلى API أو لوحة تحكم، يكفي كتابة صنف جديد يطبق `ProfileRepository` وتمريره في `main.ts`.

## الحركة

- شعار LM يظهر عند فتح الصفحة وتمر عليه لمعة ذهبية.
- الأقسام تصعد بنعومة عند ظهورها، وخط رحلة العمل يمتلئ خطوة بعد خطوة.
- نقش الهوية يتحرك ببطء في الخلفية، والأيقونات ترتسم عند مرور الماوس.
- كل الحركة تتوقف لمن فعّل خيار تقليل الحركة في جهازه، والمحتوى ظاهر دائماً دون انتظار الحركة.
- الوضع الداكن يتبع إعداد الجهاز.
